# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected security or privacy vulnerability. Email `anthologyshelf@proton.me` with a concise description, reproduction steps, affected versions, and potential impact.

Please avoid accessing data that is not your own, disrupting the hosted service, or publicly disclosing the issue before a fix is available.

## Scope

The latest production release is supported. Security fixes may also be applied to the current development branch when a release is pending.
